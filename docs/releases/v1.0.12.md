## AgentTally 1.0.12 (代理指示)

### New

- **Board layout for Active.** A List/Board switch in the top bar of the Active tab lays sessions out
  in four columns: Waiting, In progress, Done, and Background. List stays the default, and the other
  tabs stay lists.
  - Each session is one card. Its header works like a list card: click it to jump to the session.
  - Below the header, the card shows the conversation's latest 5 messages, the first sentence of each
    of your prompts and the agent's replies, so you can see where a session stands at a glance.
    "N earlier" expands the card to show everything; a long card scrolls inside itself so the other
    cards in its column stay on screen.
  - Messages come from the transcripts Claude Code and Codex already keep on your Mac. Nothing is
    summarized by a model or sent anywhere. Other agents' sessions, such as opencode and pi, show their
    card without messages.

### Changed

- **Notices only when you're needed.** AgentTally now calls for you when a task finishes, asks you
  something, or waits for your permission, and stays quiet while an agent is still working.
  - When a Codex thread uses automatic review, Codex's reviewer answers its permission requests
    without asking you, so they no longer show "Permission" with a notice and sound; the session
    keeps showing Working.
  - `codex exec` runs and temporary Codex threads (batch jobs, scheduled automations, tasks other
    agents delegate to Codex) are no longer listed, so their results don't call for you. Sessions
    the Feishu bridge runs through `codex exec` still show.
  - A Claude Code turn that ends with background tasks still running shows as Background right away,
    without a notice, menu bar dot, or sound, instead of first calling as Done. When the tasks wake
    Claude and that turn ends, you get the notice then.

## AgentTally 1.0.12（代理指示）

### 新增

- **“活跃”页可切换成看板**：“活跃”页顶栏多了“列表/看板”切换。看板按状态分成四栏：等回答、进行中、已完成、后台。
  默认仍是列表，其他页签不变。
  - 每个会话一张卡片。卡片标题和列表里的一样，点一下跳到对应会话。
  - 标题下面显示这个会话最近 5 条消息，你的要求和助手的回复各取第一句，一眼就能看出会话进行到哪了。
    点“更早 N 条”在卡片里展开全部；内容太长时在卡片里滚动，同一栏的其他卡片不会被挤出屏幕。
  - 消息读自 Claude Code 和 Codex 本来就存在你电脑上的对话记录，不调用模型总结，也不往外发送。
    其他客户端（如 opencode、pi）的会话只显示卡片，不显示消息。

### 变化

- **只在需要你介入时提醒**：任务完成、向你提问、等你授权时才提醒；助手还在干活时不打扰。
  - Codex 线程开了自动审查时，授权请求由 Codex 的审查模型直接处理、不会问你，所以不再显示“等你授权”、不弹浮窗、不响提示音，会话继续显示“工作中”。
  - `codex exec` 跑的任务和 Codex 的临时线程（批处理、定时自动化、别的助手转交给 Codex 的任务）不再列出，结束时也不提醒。
    飞书桥接通过 `codex exec` 跑的会话照常显示。
  - Claude Code 一轮结束时后台还有任务，直接显示“后台”，不弹浮窗、不显示菜单栏圆点、不响提示音，不再先按“已完成”提醒一次。
    后台任务唤醒 Claude、那一轮结束时再提醒。
