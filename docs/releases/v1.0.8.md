## AgentTally 1.0.8 (代理指示)

### Fixed

- **A Feishu bridge run you stop no longer shows as working.** The stop button in Feishu ends the
  bridge's Claude Code or Codex process before it can report that the turn ended, so the session
  used to show "Working" in Active and in the floating notices until the next message. It now shows
  as Idle once its process is gone, with no notice, and moves to Recent 10 minutes after its last
  activity. A run still in progress, and a result you have not seen yet, show as before.

## AgentTally 1.0.8（代理指示）

### 修复

- **在飞书里停止的桥接运行，不再一直显示“工作中”**：飞书的“停止”按钮会直接结束桥接的 Claude Code 或 Codex 进程，进程来不及报告这一轮已经结束，会话就一直在“活跃”和浮窗里显示“工作中”，直到你发下一条消息。现在进程一结束，会话就显示“闲置”，不弹提醒，最后一次活动 10 分钟后移到“最近”。还在跑的运行、没看过的结果，显示和以前一样。
