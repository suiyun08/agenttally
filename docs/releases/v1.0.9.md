## AgentTally 1.0.9 (代理指示)

### Fixed

- **A Codex Desktop turn you stop no longer shows as working.** Codex reports nothing when you stop
  a turn in Codex Desktop, and Codex Desktop keeps running, so the session used to show "Working"
  until the next message. AgentTally now reads Codex's own record of the turn and
  shows it as Idle, with no notice. Sending another message shows it as working again.
- **A Claude Code session no longer gets stuck on "Compacting".** While a session waits, Claude Code
  prepares a summary in the background and uses it only with your next message, so the session used
  to show "Compacting" until then. It now keeps its state: an unread result stays unread and a
  question stays waiting. Compaction you start with `/compact`, or one during a turn, shows as
  before. A session already stuck recovers with its next message.

## AgentTally 1.0.9（代理指示）

### 修复

- **在 Codex 桌面版里停止的一轮，不再一直显示“工作中”**：在 Codex 桌面版点停止时，Codex 不会通知
  AgentTally，而 Codex 桌面版本身一直开着，会话就一直显示“工作中”，直到你发下一条消息。现在
  AgentTally 会读取 Codex 自己对这一轮的记录，显示为“闲置”，不弹提醒。再发一条消息会照常回到“工作中”。
- **Claude Code 会话不再卡在“压缩中”**：会话等你回复时，Claude Code 会在后台提前准备压缩摘要，等你发下一条
  消息才用上，会话就一直显示“压缩中”。现在会保持原来的状态：没看的结果仍是未读，等你回答的问题仍在等。
  你用 `/compact` 手动压缩，或一轮进行中的压缩，显示和以前一样。已经卡住的会话，发下一条消息就会恢复。
