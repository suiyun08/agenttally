## AgentTally 1.0.0 (代理指示)

The first release of AgentTally, a menu bar indicator for AI coding sessions. It began as a fork
of [cctop](https://github.com/st0012/cctop) 0.21.4 by Stan Lo and is now developed on its own.

### What's new since cctop 0.21.4

- **Menu bar dots, grouped by agent.** One dot per session behind each agent's icon (Claude,
  Codex, DeepSeek, opencode, pi; other agents show their name), on a small translucent pill that
  stays readable over any wallpaper. A finished result you have not read is a hollow ring.
- **Hover to peek.** Rest the pointer on the dots and the panel opens without taking keyboard
  focus; move away and it closes. A click pins it. Turn it off in Settings › General.
- **Attention tabs.** Active (working, waiting for you, unread results), Idle, Recent, Cleanup.
- **Read sync.** Reading a finished turn in Claude Desktop or Codex Desktop clears its unread dot.
- **Alerts.** A notification when a session finishes, and two separate sounds — done and needs
  you — each with its own choice, independent of notifications.
- **A glass panel.** Liquid Glass on macOS 26 with a transparency slider; drag either side edge
  to resize (it settles on three widths); drag the top bar to move it (it snaps to screen edges).
- **DeepSeek Harness (DSH) support** through a native plugin, installed from Settings › Tools.
- **简体中文界面** (Settings › Appearance › Language).
- **New name and identity.** AgentTally copies cctop's settings on first launch. Launch at Login,
  notification, and Automation permissions need to be granted again for the new app.

### Known limits

- The builds are not notarized by Apple: allow the first launch as described below.
- No automatic updates yet: download the next release and replace the app.

## AgentTally 1.0.0（代理指示）

代理指示的第一个正式版本：在菜单栏里显示各个 AI 编程会话的状态。它最初基于 Stan Lo 的
[cctop](https://github.com/st0012/cctop) 0.21.4，现在独立开发。

### 相对 cctop 0.21.4 的变化

- **菜单栏按 agent 分组的指示灯**：每个会话一个圆点，排在对应 agent 的图标后面（Claude、Codex、
  DeepSeek、opencode、pi；其他 agent 显示名称），底下垫一层半透明胶囊，任何壁纸上都看得清。
  已完成但还没看的结果显示为空心圆环。
- **悬停展开**：鼠标停在指示灯上，面板展开但不抢键盘焦点；移开后自动收起，点一下就固定。
  可在「设置 › 通用」关闭。
- **按注意力分页**：活跃（工作中、等你处理、未读结果）、闲置、最近、清理。
- **已读同步**：在 Claude 桌面版或 Codex 桌面版里看过的结果，这里的未读标记会自动清掉。
- **提醒**：会话完成时发通知；「任务完成」和「等你回复」两种提示音各自可选，并且和通知分开设置。
- **毛玻璃面板**：macOS 26 使用液态玻璃，可调透明度；拖左右边缘调宽度（自动吸附三档），
  拖顶栏移动位置（自动贴屏幕边缘）。
- **支持 DeepSeek Harness（DSH）**：原生插件，在「设置 › 工具」里安装。
- **简体中文界面**（「设置 › 外观 › 语言」）。
- **新名称与新身份**：首次启动会沿用 cctop 的设置；登录时启动、通知和终端控制权限需要在新 App 下重新授权。

### 已知限制

- 安装包没有经过 Apple 公证，第一次打开需要按下面的说明放行。
- 暂不支持自动更新：新版本发布后下载替换即可。
