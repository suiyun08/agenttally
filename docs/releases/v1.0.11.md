## AgentTally 1.0.11 (代理指示)

### Changed

- **A turn you've read keeps showing its background tasks.** When Claude Code ends a turn with
  background tasks still running, it shows as Done, unread, as before. Once you read it, it now shows
  as Background and stays in Active, after unread results, instead of moving to Idle, so you can see
  that work is still out. It brings no floating notice, menu bar dot, or sound. When the tasks wake
  Claude, it shows Working again. Scheduled wakeups alone don't count, since nothing runs until they
  fire.

## AgentTally 1.0.11（代理指示）

### 改动

- **读过之后，仍能看到还有后台任务**：Claude Code 一轮结束时后台还有任务，和以前一样先显示“已完成”（未读）。
  你读过之后，现在显示为“后台”，留在“活跃”里，排在未读结果后面，不再移到“闲置”，一眼就能看出还有任务在跑。
  它不弹浮窗、不显示菜单栏圆点、不响提示音。后台任务唤醒 Claude 后，变回“工作中”。只设了定时唤醒、没有后台任务的不算，
  因为到点之前什么都没在跑。
