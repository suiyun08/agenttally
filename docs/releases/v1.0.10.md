## AgentTally 1.0.10 (代理指示)

### Fixed

- **A Codex Desktop turn you stop now stays Idle.** In 1.0.9 it showed as working again whenever
  Codex had been idle for a while: Codex then closes its turn records in a way macOS couldn't read,
  so AgentTally lost track of the stop. AgentTally now reads them either way and still only reads,
  without touching Codex's files.

## AgentTally 1.0.10（代理指示）

### 修复

- **在 Codex 桌面版里停止的一轮，现在会一直显示“闲置”**：1.0.9 里，Codex 闲置一段时间后，它会关闭自己的轮次记录，
  关闭后的记录 macOS 自带的读取方式打不开，AgentTally 读不到停止记录，会话又显示回“工作中”。现在无论 Codex
  是否开着这份记录都能读到。AgentTally 仍然只读，不改动 Codex 的任何文件。
